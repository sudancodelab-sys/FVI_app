# خريطة كتاب Kids English 1

**الحالة:** اكتمل الكتاب بعد اعتماد المستخدم لترتيب صفحة التدريب والغلاف.

## الهدف

مستوى تأسيسي للأطفال لتعرّف الحروف الإنجليزية الكبيرة والصغيرة وكتابتها في مواضعها الصحيحة على أربعة أسطر، مع كلمة مثال لكل حرف، ومحادثتين قصيرتين، والتعريف بالنفس.

## ترتيب صفحات A4

| الصفحة | المحتوى |
|---:|---|
| 1 | الغلاف المعتمد مع شعار المعهد وحقل Student Name |
| 2 | المحتويات وخريطة الحروف |
| 3 | مقدمة قصيرة وخطوات Look · Say · Copy · Write |
| 4 | شرح الخط العلوي والأوسط والأساسي والسفلي بمثال بصري |
| 5–30 | صفحة تدريب لكل حرف A–Z بالترتيب الأبجدي |
| 31 | محادثة Hello, Friend! |
| 32 | محادثة In the Classroom |
| 33 | This Is Me! — التعريف بالنفس |
| 34 | شهادة إتمام المستوى |

تتضمن المحادثتان تدريب سؤال وجواب وكلمات مفيدة، وتمنح صفحة التعريف بالنفس الطفل سطرين إضافيين للكتابة على guide lines.

## بنية صفحة الحرف

في مجموعة الأسطر الأربعة الأولى تُطبع أربعة نماذج كبيرة سوداء، يليها سطر فارغ يكتب فيه الطالب. ثم أربعة نماذج صغيرة سوداء وسطر فارغ، ثم كلمة المثال داخل أربعة أسطر وسطر فارغ آخر. تباعد الأسطر أوسع من النموذج الأولي السابق لترك مساحة كافية ليد الطفل.

| الحرف | المثال | الحرف | المثال |
|---|---|---|---|
| A a | apple | N n | nest |
| B b | ball | O o | orange |
| C c | cat | P p | pencil |

## معايير الإنتاج

- محتوى صفحات الطالب باللغة الإنجليزية المبسطة؛ الملاحظات الداخلية في هذا الملف بالعربية فقط.
- جميع نماذج الحروف والكلمات سوداء واضحة، داخل خطوط التدريب الأربعة.
- الغلاف يحافظ على بنية أغلفة السلسلة، ويتضمن شعار المعهد وحقل اسم الطالب.
- المقاس A4، وعدد الصفحات 34.
- بناء الكتاب والتحقق منه: `python3 curriculum/english/kids-1/build_kids_book.py`.
- المخرجات: `dist/kids1-book.pdf` و`dist/kids1-cover.pdf` ونسخة HTML قابلة لإعادة البناء.
