# تطبيق الطالب

تطبيق Flutter لطلاب معهد الرؤية المستقبلية: منهج الإنجليزية بمستوياته العشرة، مع صوت لكل جملة. الخطة في [`docs/APP-PLAN.md`](../../docs/APP-PLAN.md).

## التشغيل

```bash
# 1. ملفات المحتوى من الكتب المعتمدة (لا تُرفع إلى المستودع)
python3 curriculum/tools/export_app.py --out apps/student/assets/content

# 2. التطبيق
cd apps/student
flutter run                      # على هاتف أو محاكي أندرويد
flutter build web --release --no-web-resources-cdn   # نسخة للمعاينة في المتصفح
```

## أجزاء الكود

| الملف | الوظيفة |
|---|---|
| `lib/src/content/` | قراءة المستويات المصدّرة. كل نص له صوت يحمل رقم مقطعه الثابت (`a`) ومن يقوله (`v`). |
| `lib/src/audio/speaker.dart` | المشغّل الوحيد في التطبيق: تشغيل مقطع يوقف الذي قبله، والخروج من الدرس يوقف الصوت. |
| `lib/src/screens/lesson/sections.dart` | أقسام كل نوع من الدروس كما في الكتب، وقائمة مقاطع الدرس بترتيب ظهورها. |
| `lib/src/widgets/marked_text.dart` | علامات الكتب: القواعد، والكلمات المفتاحية، والتعابير، وحروف الصوتيات. |

الخطوط: Lexend للنص الإنجليزي كما في الكتب، وCairo للعربية والواجهة، وجزء من Noto Sans لرموز IPA. كلها برخصة OFL.
