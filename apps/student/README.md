# تطبيق الطالب

تطبيق Flutter لطلاب معهد الرؤية المستقبلية: منهج الإنجليزية بمستوياته العشرة، نصوصاً مع تمارين لكل درس، بلا صوت (القرار 44). لغة التطبيق الإنجليزية، والعربية إن اختارها الطالب (القرار 45). الخطة في [`docs/APP-PLAN.md`](../../docs/APP-PLAN.md).

## التشغيل

```bash
# 1. ملفات المحتوى من الكتب المعتمدة، ثم تشفير كل مستوى بمفتاحه (لا تُرفع إلى المستودع)
python3 curriculum/tools/export_app.py --out build/content
dart run content_builder build          # بمفاتيح keys/dev (القرار 49)

# 2. التطبيق
cd apps/student
flutter run                      # على هاتف أو محاكي أندرويد
flutter test                     # الاختبارات
flutter build web --release --no-web-resources-cdn   # نسخة للمعاينة في المتصفح
```

## أجزاء الكود

| الملف | الوظيفة |
|---|---|
| `lib/src/content/` | قراءة المستويات: فهرسها مقروء، وكل مستوى يُفك تشفيره بمفتاحه من التفعيل، ومعه تمارين كل درس. |
| `lib/src/activation/` | التفعيل: مفتاح الجهاز، وبيانات الطالب، والصلاحيات ومفاتيحها في التخزين الآمن، وفحص ساعة الهاتف. |
| `lib/src/screens/gate.dart`, `onboarding/` | أول تشغيل حسب التصميم المعتمد: الترحيب واللغة، والبيانات وطلب التفعيل عبر واتساب، وانتظار الكود. |
| `lib/src/language.dart` | لغة التطبيق: الإنجليزية، أو العربية إن اختارها الطالب من زر الشاشة الأولى، ويبقى اختياره محفوظاً. |
| `lib/src/screens/lesson/sections.dart` | أقسام كل نوع من الدروس كما في الكتب. الشرح العربي للقواعد يظهر في العربية فقط. |
| `lib/src/screens/exercise_screen.dart` | تمارين الدرس، تمريناً بعد تمرين: الجواب الصحيح فوراً، ثم النتيجة. |
| `lib/src/audio/speaker.dart` | المشغّل الصوتي من الخطة الأولى. لا يستخدمه التطبيق الآن، وبقي إن عاد المعهد إلى الصوت. |
| `lib/src/widgets/marked_text.dart` | علامات الكتب: القواعد، والكلمات المفتاحية، والتعابير، وحروف الصوتيات. |

الخطوط: Lexend للإنجليزية كما في الكتب (الدروس، والواجهة بالإنجليزية)، وCairo للعربية، وجزء من Noto Sans لرموز IPA. كلها برخصة OFL.
