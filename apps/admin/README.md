# تطبيق الإدارة

تطبيق Flutter لإدارة معهد الرؤية المستقبلية، بالعربية كاملاً: يقرأ رسالة طلب التفعيل التي يرسلها الطالب عبر واتساب، ويُصدر كود التفعيل ويرسله، ويحفظ سجل الطلاب ونسخته الاحتياطية. يعمل على هاتف واحد، بلا إنترنت وبلا خادم. الشاشات على التصاميم المعتمدة A1 إلى A6 ([`docs/design/screens/`](../../docs/design/screens/))، والمتطلبات في [`docs/REQUIREMENTS.md`](../../docs/REQUIREMENTS.md) (4 و5).

## التشغيل

```bash
# 1. فهرس المحتوى (شجرة الأقسام والمستويات)، يكتبه بناء المحتوى مع تطبيق الطالب
python3 curriculum/tools/export_app.py --out build/content
dart run content_builder build          # يكتب apps/admin/assets/content/index.json أيضاً

# 2. التطبيق
cd apps/admin
flutter run                      # بمفاتيح التطوير
flutter test                     # الاختبارات
flutter build web --release --no-web-resources-cdn   # نسخة للمعاينة في المتصفح
```

نسخة التطوير تستعمل مفاتيح `keys/dev` وحدها، فأكوادها لا تفتح إلا تطبيق الطالب المبني بها. نسخة الإنتاج تُبنى بـ `--dart-define=FVI_PRODUCTION=true`: لا مفاتيح فيها، فيصنعها الإعداد الأول على الهاتف أو يستوردها من ملف بكلمة سر (زر «استعادة من نسخة احتياطية»). ومفاتيح الإنتاج لا تُرفع إلى المستودع أبداً.

## أجزاء الكود

| الملف | الوظيفة |
|---|---|
| `lib/src/data/admin.dart` | حالة التطبيق: رمز الدخول، والمفاتيح، وإصدار الأكواد والتجديد، ورقم واتساب، والنسخ الاحتياطي. السجل مشفّر بمفتاح في التخزين الآمن. |
| `lib/src/data/records.dart` | سجل الطلاب: طالب لكل جهاز، وأكواده وصلاحياتها، وحالته (فعّال، قريباً، منتهٍ)، وتنبيهات الطلب (جهاز معروف، أو اسم أو رقم بجهاز آخر). |
| `lib/src/data/secrets.dart` | مفاتيح المعهد، وملف النسخة الاحتياطية المشفّر بكلمة سر، وبصمة رمز الدخول. |
| `lib/src/data/catalog.dart` | شجرة المحتوى من فهرس تطبيق الطالب، بأسمائها العربية. |
| `lib/src/screens/lock.dart` | A1: القفل ولوحة الأرقام والبصمة، والإعداد الأول. |
| `lib/src/screens/home.dart` | A2: لوحة الإدارة وتبويباتها. |
| `lib/src/screens/new_activation.dart` | A3: لصق الرسالة، وشجرة ما يُفتح، والمدة، والإصدار عبر واتساب. |
| `lib/src/screens/students.dart` | A4 وA5: سجل الطلاب، وتفاصيل الطالب والتجديد. |
| `lib/src/screens/settings.dart` | A6: النسخ الاحتياطي والاستعادة، ورقم واتساب، والأمان. |

الخطوط: Cairo للعربية، وLexend لأسماء المستويات والأرقام اللاتينية. كلاهما برخصة OFL.
